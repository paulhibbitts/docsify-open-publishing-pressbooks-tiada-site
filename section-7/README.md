### Key Takeaways

1. Context – the learning environment – will influence or determine teaching strategies, as well as epistemology and pedagogy
2. Thus to be able to design effective teaching, it is necessary to create an effective learning environment.
3. Digital technology allows for the creation of significantly different learning environments from the traditional classroom environment.
4. All effective learning environments need a number of different components, and these components will vary, depending on context and the epistemology that drives teaching.
